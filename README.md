# Бот учёта оплат занятий

Телеграм-бот, который читает ваше расписание из Google Календаря, показывает
занятия по неделям, позволяет отмечать оплату одним нажатием и считает итоги.

Что он умеет:

* берёт занятия прямо из вашего Google Календаря — вести расписание заново не нужно;
* показывает **прошлую, текущую и следующую** неделю;
* каждое занятие — кнопка: тап → «оплачено», повторный тап → отметка снимается;
* считает итоги: сколько проведено, оплачено, сколько ждём и на какую сумму;
* запоминает цены по названиям занятий и подставляет их автоматически;
* сам присылает итоги недели (по умолчанию — в воскресенье в 20:00);
* понимает переносы и отмены занятий в календаре.

Ничего доустанавливать не нужно: бот написан на стандартном Python 3.10+.

---

## Что нужно сделать один раз

### 1. Создать бота в Telegram

1. Откройте в Telegram **@BotFather** (это официальный бот Telegram).
2. Отправьте ему команду `/newbot`.
3. Придумайте имя (любое, например `Мои занятия`) и адрес бота
   (латиницей, обязательно заканчивается на `bot`, например `my_lessons_pay_bot`).
4. BotFather ответит строчкой вида:

   ```
   Use this token to access the HTTP API:
   7123456789:AAH8xLzQwErTyUiOpAsDfGhJkLzXcVbNm
   ```

   Это **токен** — длинная строчка с двоеточием. Скопируйте её, она нужна в шаге 3.

> Если токен случайно попал к кому-то ещё — в BotFather есть `/revoke`, он выдаст новый.

### 2. Взять ссылку на календарь

В Google Календаре:

1. Слева наведите на нужный календарь → три точки → **«Настройки и уведомления»**.
2. Прокрутите вниз до блока **«Секретный адрес в формате iCal»**
   (по-английски *Secret address in iCal format*).
3. Скопируйте эту ссылку целиком. Она выглядит примерно так:

   ```
   https://calendar.google.com/calendar/ical/ваш_адрес%40gmail.com/private-длинный-код/basic.ics
   ```

> В заголовке статьи Google написано «секретный» — это значит, что по ссылке
> календарь читает любой, кому она известна. Никому её не пересылайте.
> Ссылку можно в любой момент сбросить в тех же настройках.

### 3. Заполнить настройки

1. В папке с ботом скопируйте файл `.env.example` и назовите копию `.env`.

   В Проводнике: правая кнопка на `.env.example` → «Копировать», затем
   «Вставить», и переименуйте копию в `.env`.

2. Откройте `.env` блокнотом и заполните две строки:

   ```
   BOT_TOKEN=7123456789:AAH8xLzQwErTyUiOpAsDfGhJkLzXcVbNm
   ICAL_URL=https://calendar.google.com/calendar/ical/.../basic.ics
   ```

3. Проверьте строку с ключевыми словами — по ним бот понимает, что событие
   является занятием:

   ```
   LESSON_KEYWORDS=урок,занятие
   ```

   Впишите то, что реально есть в названиях ваших занятий. Можно несколько
   слов через запятую. Регистр и буква «ё» не важны: «Урок», «УРОК» и «урок»
   находятся одинаково.

Сохраните файл.

### 4. Запустить

Откройте папку с ботом в Проводнике, щёлкните по адресной строке, введите `cmd`
и нажмите Enter. В открывшемся окне выполните:

```
python main.py
```

Должно появиться примерно такое:

```
База данных: C:\...\lesson-pay-bot\data\bot.db
Читаю календарь при запуске…
✅ Календарь прочитан в 14:32
Занятий найдено: 24
Новых добавлено: 24
```

Теперь откройте своего бота в Telegram и отправьте ему `/start`.

> Окно `cmd` должно оставаться открытым — пока оно открыто, бот работает.
> Закрыли окно — бот уснул. Сообщения, написанные ему в это время, Telegram
> придержит и доставит при следующем запуске.

## Как этим пользоваться

Отправьте боту `/start` или `/неделя` — он пришлёт текущую неделю:

```
📅 Неделя 19–25 октября (текущая)

Вт 20.10
   🕗 15:00  Математика (Аня) — 1 500 ₽
Ср 21.10
   🕗 17:00  Физика (Игорь) — 2 000 ₽

Занятия: проведено 0 · оплачено ✅ 0 · впереди 🕗 2
Деньги: впереди на 3 500 ₽ · всего за неделю 3 500 ₽
```

Под сообщением — кнопки:

| Кнопка | Что делает |
|---|---|
| `🕗 Ср 21.10 17:00 · Физика (Игорь)` | отметить занятие оплаченным / снять отметку |
| `✅ Всё оплачено` | отметить всю неделю сразу |
| `⭕ Снять отметки` | снять все отметки за неделю |
| `💰 Задать цены` | список занятий, чтобы задать стоимость |
| `◀️ Прошлая` / `Текущая` / `Следующая ▶️` | перелистывание недель |
| `📊 Итоги недели` | подробные итоги |
| `🔄 Обновить` | перечитать календарь прямо сейчас |

Значки:

* ✅ — оплачено
* ⭕ — проведено, но ещё не оплачено
* 🕗 — занятие ещё не наступило

### Задать цену

Цена задаётся один раз для каждого названия занятия. Два способа:

* **Кнопками:** `💰 Задать цены` → выбрать занятие → прислать число.
* **Сообщением:** написать `Математика 1500` или `/цена Математика 1500`.

Бот запомнит и будет подставлять эту цену везде сам. Название можно писать
частично — достаточно куска названия, например `физика 2000`.

### Команды

| Команда | Что делает |
|---|---|
| `/start` | начать и показать текущую неделю |
| `/неделя` | текущая неделя |
| `/прошлая` | предыдущая неделя |
| `/следующая` | следующая неделя |
| `/итоги` | итоги недели + разбивка по занятиям |
| `/статистика` | сводка по всем неделям и общий долг |
| `/цены` | список заданных цен |
| `/цена Математика 1500` | задать цену |
| `/обновить` | перечитать календарь |
| `/помощь` | подсказка |

Команды можно писать без косой черты: `неделя`, `итоги`, `статистика`.

## Автоматический запуск при включении компьютера (по желанию)

Чтобы не запускать бота вручную каждый раз:

1. Убедитесь, что он вообще работает командой `python main.py`.
2. Нажмите `Win + R`, введите `shell:startup` и нажмите Enter.
   Откроется папка «Автозагрузка».
3. Щёлкните в ней правой кнопкой → «Создать» → «Ярлык».
4. В поле «Расположение объекта» вставьте (замените путь на свой):

   ```
   "C:\Windows\System32\cmd.exe" /c cd /d "C:\путь\к\lesson-pay-bot" && python main.py
   ```

5. Назовите ярлык, например `Бот оплат`, и нажмите «Готово».

Теперь бот будет подниматься сам при включении компьютера.

## Если что-то не работает

**«Не хватает настроек: Не задан BOT_TOKEN»**
Файл `.env` не создан, или в нём пустое значение. Проверьте, что файл лежит
в одной папке с `main.py` и называется ровно `.env` (без `.txt` на конце).
В Проводнике включите «Расширения имён файлов» на вкладке «Вид», чтобы видеть
настоящее имя.

**«Google отказал в доступе к календарю»**
Ссылка скопирована не полностью, или доступ к календарю закрыт. Скопируйте
ссылку заново целиком.

**Бот не находит занятия**
Не совпадают ключевые слова. Посмотрите, как занятия называются в календаре,
и впишите это в `LESSON_KEYWORDS`. Можно временно поставить
`LESSON_KEYWORDS=` (пусто) — тогда бот возьмёт все события календаря.

**Занятия находятся, но время съехало**
Проверьте `TZ` в `.env`. Для Новосибирска — `Asia/Novosibirsk`.

**Бот молчит после запуска**
Проверьте, что токен в `.env` скопирован без пробелов и целиком.

## Файлы

| Файл | Назначение |
|---|---|
| `main.py` | запуск бота |
| `bot.py` | логика бота и тексты сообщений |
| `ical.py` | чтение календаря Google, повторы, переносы |
| `calendar_sync.py` | скачивание календаря |
| `storage.py` | база данных (SQLite) |
| `weeks.py` | недели и подсчёты |
| `tg.py` | работа с Telegram API |
| `config.py`, `tzutil.py` | настройки и часовые пояса |
| `.env` | ваши токены и параметры (создаётся вами) |
| `data/bot.db` | ваши отметки об оплате и цены |
| `test_offline.py` | самопроверка (запуск: `python test_offline.py`) |
| `demo.py` | показать вид сообщений (запуск: `python demo.py`) |

База `data/bot.db` — это ваши данные. Скопировав этот файл, вы сохраните все
отметки об оплате и цены; его стоит изредка бэкапить.
